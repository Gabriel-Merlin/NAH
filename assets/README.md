# Dossier assets

Place ici les images du site.

## Image à fournir

- **`lycee-marceau.jpg`** — photo du Lycée Marceau utilisée en arrière-plan du bandeau
  sur toutes les pages.
  - Format paysage recommandé : **1600 × 600 px** minimum.
  - Poids conseillé : moins de **300 Ko** (optimise-la, ex. avec [squoosh.app](https://squoosh.app)).
  - ⚠️ **Autorisation requise** du chef d'établissement pour utiliser une photo du lycée.

Tant que la photo n'est pas ajoutée, le bandeau s'affiche avec un fond bleu uni
(le voile bleu du brief). Dès que tu déposes `lycee-marceau.jpg` ici, elle apparaît
automatiquement sous le voile.
